📊 Netflix Descriptive Analytics

A Descriptive Analytics project on Netflix Titles using IBM Cognos Analytics.
The project analyzes Netflix Movies and TV Shows to understand content distribution, yearly trends, and country-wise contributions through interactive visualizations.

---

🚀 Project Overview

This project focuses on analyzing the Netflix Titles dataset and extracting meaningful insights from the available data.

The analysis uses IBM Cognos Analytics to create different visualizations and explore:

- 📅 Year-wise Netflix title growth
- 🎬 Movies vs TV Shows distribution
- 📈 Yearly content trends
- 🌍 Country-wise title distribution
- 📊 Visual comparison of Netflix content

The main objective is to understand how Netflix content is distributed across years, content types, and countries.

---

🎯 Objectives

The major objectives of this project are:

1. Analyze the number of Netflix titles released over different years.
2. Compare the distribution of Movies and TV Shows.
3. Identify yearly trends in Netflix content.
4. Analyze Netflix titles based on country.
5. Present the findings using clear and interactive visualizations.

---

📁 Dataset

The project uses the Netflix Titles dataset:

netflix_titles.csv

Important fields used in the analysis include:

Field| Description
"show_id"| Unique ID of the Netflix title
"type"| Movie or TV Show
"release_year"| Release year of the title
"country"| Country associated with the title

---

📊 Analysis Performed

1. Year-wise Title Count

A year-wise analysis was performed using:

- "release_year"
- "show_id"

This visualization helps understand the growth and distribution of Netflix titles across different years.

---

2. Movies vs TV Shows

The project compares Netflix content based on the "type" field.

The two major categories are:

- 🎬 Movies
- 📺 TV Shows

A visual comparison was created to understand the proportion of each content type.

---

3. Yearly Title Trend

A Line Chart was created in IBM Cognos Analytics.

X-axis: "release_year"
Y-axis: "Count(show_id)"

This visualization represents how the number of Netflix titles changes across different years.

---

4. Movies vs TV Shows Distribution

A Pie Chart was used to represent the distribution of:

- Movies
- TV Shows

This provides an easy-to-understand view of the content composition of the Netflix dataset.

---

5. Country-wise Title Analysis

The project also analyzes Netflix titles based on the "country" field.

This helps identify countries that contribute significantly to the Netflix content catalog.

Countries such as United States, India, and United Kingdom are highlighted in the analysis.
